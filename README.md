# AURA AI — Real-Time Visual Intelligence

AURA AI is a computer vision project built around real-time visual interaction, facial analysis, and an interactive web experience.

The project combines browser-based vision libraries with a modern frontend to explore how visual information can be processed and presented in real time.

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Computer Vision:** MediaPipe Tasks Vision, face-api
- **3D & Animation:** Three.js, React Three Fiber, Framer Motion

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/).

### Installation

```bash
git clone https://github.com/Velikantithanmayee/aura-ai-visual-intelligence.git
cd aura-ai-visual-intelligence
npm install
npm run dev
```

Open the local URL provided by Vite in your browser.

### Production Build

```bash
npm run build
```
